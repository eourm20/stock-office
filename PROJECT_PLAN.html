08 — 신뢰성과 안전 조건

Investment decisions

  • 시세·기사·공시의 observed/available/ingested 시각 별도 기록
  • 인용 불충분·도구 실패 시 REVIEW 처리
  • LLM 확신도는 수익 확률로 표현하지 않기
  • 실제 주문 API 호출과 계좌 연결 없음

Measuring actual results

  • 신호 품질과 체결 수익률, 포트폴리오 NAV 구분
  • 동일 기간·자본·수수료로 전략 A/B/C/D 비교
  • 중복 주문 키, 정합성 원장, 거래소 휴장일 처리
  • 실행 시간·LLM 비용·오류·데이터 부족 함께 기록

09 — Sprint 0 종료 게이트 (통과)

FIRST WORKING VERTICAL SLICE

NVDA / 삼성전자(005930) → AI 분석 → Agent 실행 이벤트 → JSON 결과/리플레이

첫 단계에서는 화려한 화면이나 실거래 기능을 구현하지 않는다. 두 시장의 데이터 호환, LangGraph 이벤트 추출, 데이터 공개 시점, 보고서 저장, 에러 처리, 비용과 실행 시간을 측정한다. API 키가 없어 모의 fixture만 검증한 경우 실제 분석 성공으로 표시하지 않는다.

결과(2026-10-16): NVDA·005930 실제 분석 완료, 각 35개 이벤트 순서 저장·재생, 실행당 약 $0.04 (economy). 상세는 docs/sprint-0-report.md.

10 — 포트폴리오 기록 계획

코드 저장소·아키텍처·에이전트 실행 스냅샷·종목별 데이터 호환성·비용/지연시간·동일 조건 전략 비교 리포트를 단계마다 쌓는다. 노션 경험창고에는 기획과 실제 구현 결과를 구분한다. 과거 투자 AI의 부진한 결과를 개선 목표로 활용하되, 새 버전의 성과는 검증 전까지 주장하지 않는다.
