# Stock Office

Planning-first starter pack for the AI-driven virtual investment office. **No implementation or live trading is included in this archive.**

- `PROJECT_PLAN.html`: visual full-product overview (open in a browser)
- `IMPLEMENTATION_PLAN.md`: requirements, screens, architecture, models, roadmap, acceptance
- `CODING_AI_PROMPT.md`: paste into a coding AI to start Sprint 0
- `CLAUDE.md`: persistent repository-level rules for Claude Code

## Getting started
1. Copy these files to your local `stock-office/` root.
2. Open `PROJECT_PLAN.html` to review scope.
3. Start Claude Code in the root so it reads `CLAUDE.md`.
4. Send the instructions in `CODING_AI_PROMPT.md` to initiate Sprint 0.
5. Do not supply real trading credentials: all MVP orders are paper-only.
