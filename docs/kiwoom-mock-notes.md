# 키움 모의투자 연동 메모 (K0, 2026-10-20)

K단계 준비용으로 확인한 사실과 아직 확인이 필요한 점. 출처를 함께 적는다. 키·계좌번호는 이 문서에 적지 않는다.

## 출처
- 키움 공식 GitHub: https://github.com/Kiwoom-Securities/Kiwoom-REST-API (예제·`.env.example`·README)
- 사용자 레포(읽기 전용): `kiwoom-api-mcp-server` (국내 API 카탈로그 208개, 토큰·연속조회 코드)
- 사용자 레포(읽기 전용): `quant-trading` `feature/agent-mode` (2026-03~04 키움 모의투자 실제 운영 기록: `worker/clients/kiwoom_client.py`, `worker/portfolio_sync.py`, 커밋 메시지)

## 모의투자 제한 (quant-trading 운영 메모, 국내)
- **정규장(09:00~15:30)만 주문 가능.** 장전·장후 시간외(`trde_tp` 61/81)·시간외 단일가(62)는 모의에서 안 됨 → 우리 시스템도 모의에서는 정규장 지정가만 사용
- **거래소는 KRX만.** NXT·SOR 주문/조회 불가 → `dmst_stex_tp`는 항상 `KRX`
- **`kt00015`(위탁종합거래내역) 미지원** → 체결 확인은 `kt00007`(주문체결 상세)로. 2026-03 메모에는 "`kt00007`도 모의 미지원"이라 적혀 있으나 2026-04에 `KRX` 지정으로 모의 체결 동기화를 구현함 → K1에서 실제 확인
- 시장가 주문이 상·하한가 문제로 `RC4027`을 반환하는 경우가 있음(당시는 현재가 지정가로 1회 재시도). 우리는 지정가만 쓰므로 해당 없음, 오류 코드만 기록
- `RC4025`(증거금 부족)는 재시도해도 소용없음 → 리스크 거절로 보고

## K1에서 실제 모의 서버로 확인한 것 (2026-10-20 14:30, 서버 `129.154.55.33`)
- 국내·해외 모의 계좌 모두 **토큰 발급과 조회 정상**. 앱키는 계좌별로 따로(국내 1쌍, 해외 1쌍)
- 국내: `kt00001`(예수금 `entr`·주문가능 `ord_alow_amt` 있음), `kt00018`(`acnt_evlt_remn_indv_tot`, `tot_evlt_amt` 등), **`kt00007`도 모의에서 정상 응답**(`acnt_ord_cntr_prps_dtl`) → 예전 메모의 "kt00007 미지원"은 해당 없음(KRX 지정 시)
- 해외: `ust21110`(통화별 `result_list`에 USD 행, `fc_entra`·`fc_ord_alowa`), `ust21070`(`result_list`, `tot_evlt_amt` 등), `ust21510`(`result_list`) 모두 정상 → **미국주식 모의 계좌 조회 가능**
- 시작 잔고: 국내 모의 **10,000,000원**, 해외 모의 **$100,000**(달러 예수금으로 바로 있음, 원화 예수금 0)
- 확인 명령(금액 없이 필드 이름만): `cd ~/stock-office/backend && .venv/bin/python -m stock_office.kiwoom_mock.link`

## 아직 확인이 필요한 것 (K2·K3에서 모의 주문으로 확인)
1. **미국주식 모의 주문이 실제로 되는지**와 모의 미국 장 시간(정규장만인지) — 조회는 확인됨
2. **미국 소수점 주문**: 공식 미국 주문 API(`ust20000`)에는 소수점 관련 항목이 없음. 키움 소수점 매매는 앱(영웅문S글로벌)에서 신청하는 별도 서비스(원화 1달러 단위). → API로는 **정수 주만** 된다고 보고 설계하고(키움 체결 방식용 정수 주 규정 버전 추가), 모의 계좌에서 `ord_qty`에 소수를 넣었을 때의 응답으로 최종 확인
3. ~~모의 계좌의 달러 예수금~~ — 확인: $100,000 달러 예수금으로 시작(환전 불필요)
4. 모의 호출 제한(검색 결과로는 모의 계좌별 TR당 초당 1회 — 공식 페이지에서 직접 확인 못 함)
5. 모의 체결의 수수료·세금 표시 여부
6. ~~국내 `kt00007`이 모의에서 동작하는지~~ — 확인: 정상 응답(체결이 생긴 뒤 행 내용은 K2에서 확인)
